    Baltic Defence & Geopolitics Monitor

    A small data project: I scrape the Baltic public broadcasters' English news and ask how much of it is actually about defence and security and what it is about.

    Read with care

    Each broadcaster's English page carries a different mix and was scraped a different number of times.

    Open the live monitor →

    Runs itself: once a day a GitHub Action scrapes, analyses and rebuilds the page, then publishes it into this site.

    Stack: Python · web scraping · NLP (spaCy, embeddings) · HTML/CSS/JS · GitHub Actions · Claude
    Code: github.com/Jule4ka/baltics-nordics-monitor
