.. title: Baltic Defence & Geopolitics Monitor
.. slug: baltics-monitor

A small data project: I scrape the Baltic public broadcasters' English news and
ask how much of it is actually about defence and security and what it is about.
<br>

#### Read with care
Each broadcaster's English page carries a different mix and was scraped a different
number of times. 
<br>

[Open the live monitor &rarr;](/content/baltics_monitor/)
<br>

Runs itself: once a day a GitHub Action scrapes, analyses and rebuilds the page,
then publishes it into this site.
<br>

**Stack:** Python · web scraping · NLP (spaCy, embeddings) · HTML/CSS/JS · GitHub Actions · Claude
<br>
**Code:** [github.com/Jule4ka/baltics-nordics-monitor](https://github.com/Jule4ka/baltics-nordics-monitor)
